Solo shop affiliation

Simple flow for client confirmation — display only, with shop approval

A Solo barber often works inside someone else’s shop. They should be able to show that on their profile. The shop must approve first. This does not change bookings, payments, staff, or billing.

1. Solo barber asks to join a shop

1 Edit Profile

The Solo user opens Edit Profile, searches by owner name or business name, selects the shop where they work, and taps Update.

2 Request is sent — not live yet

Their profile is not linked until the shop says yes. The Solo barber also gets an in-app + push message: the request was sent, please wait, we will update you when the shop approves or declines.

2. The shop gets a notification

3 In-app + push

The shop owner gets a message in the notification panel and a phone push: this Solo barber asked to be shown as working at their shop. They have a screen to approve or reject.

4 Approve or reject
  • Approve — the Solo profile is linked for display.
  • Reject — nothing is linked. The Solo user is told it was declined.

3. After the shop approves

5 Solo user is notified

They get an in-app message and a push that the shop accepted.

6 Work address stays in the Solo owner’s control

Affiliation does not lock the address. The Solo account holder can manually add or edit their workplace location at any time (before a request, while waiting, after approval, or after a shop is removed). We may prefill the shop’s address when a request is approved, so customers start with that shop’s location — the Solo owner can change it whenever they want. Customers then see the address they saved.

4. If they later pick a different shop

7 Old shop is removed immediately

If they are already linked to shop A and then request shop B, the link with A is removed as soon as they tap Update. This happens even if B later approves or declines. A is not put back. They and shop A both get a notification. Their saved work address is not deleted. They get an update location reminder so they can review or edit it. Then they wait for B, same as a first request.

5. If the shop later removes them

8 Link is removed

The “working with” display is cleared. Their saved work address stays until they edit it.

9 They can update location themselves

They get an in-app + push notification (update location). Tapping it opens their location settings so they can keep or change the address.

6. If the Solo barber upgrades to a Business plan

10 Affiliation is removed automatically

They are no longer shown as working at the other shop. Their saved address is not deleted.

11 They can review their location

They get a notification to review or edit their work address. Same update location type.

What this is not: it does not add them to the shop’s team, does not share money, and does not change who gets booked. It is only for showing where they work, after the shop agrees. Work address is always theirs to edit.
